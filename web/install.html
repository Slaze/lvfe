 iPhone / iPad (Safari)

iOS does not show a browser install popup. Use Safari’s Share sheet. Chrome on iOS cannot add PWAs the same way — open this page in Safari.

  1. Open this game in Safari Use https://iconiaglobal.com/lvfe/ in Safari (not inside Instagram / WhatsApp in-app browsers).
  2. Tap Share The ⇧ Share icon is at the bottom (iPhone) or top (iPad).
  3. Add to Home Screen Scroll the share sheet and tap ＋ Add to Home Screen. Confirm Add.
  4. Launch from the icon Lvfe opens full-screen (standalone). Use that icon next time — not a random Safari tab.

If you do not see Add to Home Screen, you are probably not in Safari. Copy the URL → open Safari → paste → Share.

▶ Android (Chrome)

Chrome can show an Install banner. You can also install from the browser menu.

  1. Open in Chrome Visit https://iconiaglobal.com/lvfe/ over HTTPS in Chrome.
  2. Install from the banner or menu Tap ⬇ Install if prompted, or Chrome menu ⋮ → Install app / Add to Home screen.
  3. Confirm Accept the install dialog. An Lvfe icon appears on your home screen / app drawer.
  4. Open the installed app It runs without the Chrome address bar (standalone display).

The separate Android APK (sideload) is optional. This PWA install is the HTTPS path that shares Google cloud saves.

▣ Desktop Chrome / Edge

Install from the address bar or the browser menu. Firefox support varies by OS.

  1. Open the site https://iconiaglobal.com/lvfe/ in Chrome or Microsoft Edge.
  2. Install icon or menu Click the install icon in the address bar, or menu → Install Lvfe… / Apps → Install this site as an app.
  3. Confirm Install The app opens in its own window. Pin it to your dock or taskbar if you want.

☁ After install — sync saves

Installing puts the game on your device. Progress still needs Google if you want the same save on phone + desktop + APK.

  1. Sign in with Google Open Account (gold seal / profile) → Sign in with Google.
  2. Sync now Under This phone → Sync now. Guest play stays on that device only.
  3. Same Google on every client Use the same Google account on PWA and the Android APK so cloud save matches.
